# ADR-007 — Entorno de Compilación Containerizado con Docker

* **Estado:** Aceptada
* **Fecha / Hito:** 2026-09-01 (Revisión L8)

---

## Contexto

Compilar paquetes de Arch Linux directamente sobre el runner estándar de GitHub Actions (que corre sobre Ubuntu) requeriría emuladores de pacman o paquetes cruzados complejos que introducen inestabilidad.

Necesitamos un entorno idéntico al de las máquinas de destino para compilar paquetes nativos con `makepkg` y construir la base de datos `omarchy.db` con `repo-add`.

---

## Decisión

* La Action `release-personal.yml` lanza un contenedor efímero basado en la imagen oficial `docker run archlinux:base-devel`.
* Dentro del contenedor se instalan las utilidades de firma (`gnupg`, `archlinux-keyring`), se importa la clave privada desde las variables de entorno, y se construyen los paquetes en un espacio de memoria aislado.
* La imagen mutable de Arch Linux se actualiza periódicamente mediante el workflow `builder-images.yml`.

---

## Consecuencias

* **Pureza de Build:** Cada compilación arranca en un sistema operativo limpio sin residuos de ejecuciones anteriores.
* **Compatibilidad 100%:** Los binarios resultantes son paquetes nativos de Arch Linux con compresión `zstd` y firmas estándar.
