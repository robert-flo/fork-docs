# ADR-005 — Marcador `"personal": true` para Paquetes Propios

* **Estado:** Aceptada
* **Fecha / Hito:** 2026-09-01 (WORKLOG 8ª parte)

---

## Contexto

El repositorio de empaquetado `robert-flo/omarchy-pkgs` comenzó administrando únicamente el par canónico `omarchy` y `omarchy-settings`. 

Surgió la necesidad de incorporar utilidades adicionales y paquetes propios (como herramientas de prueba o webapps asociadas) para que se compilaran y publicaran en el mismo repositorio pacman sin tener que modificar la lógica del workflow de GitHub Actions cada vez.

---

## Decisión

* Todo paquete personal adicional ubicado bajo `pkgbuilds/<paquete>/` debe incluir un archivo `.omarchy/package.json` con la clave booleana:
  ```json
  {
    "source": "local",
    "release_ring": "fast",
    "personal": true
  }
  ```
* La Action `release-personal.yml` recolecta dinámicamente todos los directorios que posean `"personal": true` y los compila dentro del contenedor Docker.

---

## Consecuencias

* **Extensibilidad:** Añadir un nuevo software a la distribución personal requiere únicamente hacer commit de su receta `PKGBUILD` y su `package.json`.
* **Caso de Prueba Validado:** El paquete `hola-mundo` validó este mecanismo en producción con incrementos exitosos de versión (`0.1.0-1` → `0.1.0-2`).
